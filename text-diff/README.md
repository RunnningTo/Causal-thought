# DiffBox - 文本对比工具

一个功能强大、设计精美的文本对比工具，支持中英文智能分割和字符级精确对比。


## ✨ 特性

### 🔍 核心功能
- **Myers Diff 算法** - 与 Git 同款的差异对比算法
- **字符级精确对比** - 精确高亮每个修改的字符
- **智能分割** - 中文按句子分割，英文按行分割
- **实时统计** - 显示新增、删除、修改的行数

### 🎨 视觉设计
- **6 套主题风格** - 赛博朋克、森林绿、深海蓝、日落橙、紫罗兰、极简白
- **流畅动画** - 所有交互都有平滑过渡效果
- **响应式布局** - 完美支持桌面和移动端

### ⚡ 使用体验
- **零依赖** - 纯原生 HTML/CSS/JavaScript
- **离线可用** - 无需服务器，双击即可运行
- **快捷键支持** - `Ctrl + Enter` 快速对比
- **主题记忆** - 自动保存你的主题偏好

## 🚀 快速开始

1. 下载 `text-diff.html`
2. 双击在浏览器中打开
3. 开始对比文本

## 📖 使用说明

### 基本操作
1. **输入文本** - 在左右两个文本框中输入要对比的内容
2. **点击对比** - 点击"🔍 开始对比"按钮或按 `Ctrl + Enter`
3. **查看差异** - 查看并排对比结果

### 对比模式

#### 智能模式（默认）
- 自动检测文本语言
- 中文：按句子分割（。！？；）
- 英文：按行分割
- 适合对比论文、文章等长文本

#### 行模式
- 强制按行分割
- 不管什么语言都按换行符分割
- 适合对比代码、配置文件等

### 差异类型

| 颜色 | 类型 | 说明 |
|------|------|------|
| 🟢 绿色 | 新增 | 右侧新增的内容 |
| 🔴 红色 | 删除 | 左侧被删除的内容 |
| 🟡 黄色 | 修改 | 行内部分字符被修改 |

### 字符级高亮
对于修改的行，会精确显示：
- **红底删除线** - 被删除的字符
- **绿底加粗** - 新增的字符

## 🔧 技术实现

### 算法
- **Myers Diff** - 行级对比算法（O(ND) 复杂度）
- **LCS (Longest Common Subsequence)** - 字符级对比算法
- **Levenshtein Distance** - 相似度计算，智能检测修改

### 架构
- 纯原生 JavaScript - 无任何框架依赖
- CSS Variables - 实现主题系统
- Local Storage - 保存用户偏好

### 浏览器兼容性
- Chrome/Edge 90+
- Firefox 88+
- Safari 14+

## 🛠️ 自定义

### 添加新主题
在 CSS 中添加新的主题变量：

```css
[data-theme="你的主题名"] {
    --bg-dark: #你的颜色;
    --bg-medium: #你的颜色;
    --accent-primary: #你的颜色;
    /* ... 其他变量 */
}
```

然后在 JavaScript 的 `themes` 数组中添加：

```javascript
const themes = [
    // ...
    { id: '你的主题名', name: '显示名称', icon: '🎨' }
];
```

### 调整算法参数
在 `detectModifiedLines` 函数中调整相似度阈值：

```javascript
if (similarity > 0.3) {  // 默认 30%，可调整
    // 认为是修改
}
```
